# 武汉写字楼租户质量分析

一个可调权重的武汉写字楼租户质量分析网页，覆盖 30 栋楼宇和 61 条具名公开企业记录。

## 页面能力

- 按租户能级、产业集聚、租户稳定、经济贡献和运营市场调整权重，实时重排。
- 按行政区、运营状态和样本证据等级筛选楼宇。
- 查询每栋楼内已公开披露的企业或机构。
- 查看企业样本的审计说明、证据等级和原始来源。
- 导出当前排名及数据审计字段为 CSV。

## 数据口径

- `已交叉验证`：楼宇或企业信息有多个公开信号相互印证。
- `单一来源`：当前仅有一个可回溯来源，仍需后续复核。
- `待补充`：只有聚合描述，或尚未找到可回溯的原始来源。

企业查询只收录政府通报、开发商或物业披露、公开报道中可追溯的样本，不代表完整租户名册。“公开规模”也可能采用注册企业、招商签约或片区口径，详情页已逐栋标注。

楼宇评分是用于讨论和敏感性分析的模型，不是资产估值或权威评级。

## 使用

直接用浏览器打开 `index.html` 即可。
